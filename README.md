# МедФактЧек — бэкенд 7.3

Веб-сервис для проверки медицинских утверждений.
Проект команды 1227, кейс-чемпионат «Инновации в медицине»
(НМИЦ им. В.А. Алмазова).

## Что умеет

- Проверка медицинских утверждений: локальная база (RAG) + GigaChat с web_search.
- Проверка фото: OCR через Tesseract (rus+eng).
- Отсечение немедицинских запросов до вызова GigaChat.
- Автомодерация ответов GigaChat — 4 уровня проверки качества.
- Кэш ответов на 24 часа (хранится только хеш, без текста).
- Rate limit по реальному IP клиента (ProxyFix за прокси).
- Очередь запросов с показом позиции.
- PDF-отчёт с распознанным текстом.
- Мини-игра «Проверь свою грамотность» (20 вопросов).
- Раздел «База знаний» — только счётчик фактов, содержимое наружу не отдаётся.
- QR-код на текущий URL.

## Стек

- Python 3.10+, Flask 3.0, flask-cors
- GigaChat API (Сбер)
- Tesseract OCR
- pdfmake (PDF в браузере)
- Bootstrap 5.3

## Установка

1. Python 3.10+ с python.org (галочка «Add Python to PATH»).
2. Tesseract: https://github.com/UB-Mannheim/tesseract/wiki
