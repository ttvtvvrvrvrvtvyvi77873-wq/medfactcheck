# МедФактЧек — бэкенд 7.7

Веб-сервис для проверки медицинских утверждений. Проект команды 1227, кейс-чемпионат «Инновации в медицине» (НМИЦ им. В.А. Алмазова).

## Что умеет
- Проверка медицинских утверждений: локальная RAG-база + GigaChat с web_search.
- Проверка фото: OCR через Tesseract (рус+англ).
- Автомодерация ответов GigaChat — 4 уровня проверки качества.
- Кэш ответов на 24 часа (хранится только хеш, без текста).
- Ограничение скорости по реальному IP (ProxyFix за прокси).
- Очередь запросов с показом позиции.
- PDF-отчёт с распознанным текстом.
- Мини-игра «Проверь свою грамотность» (20 вопросов).
- Раздел «База знаний» — только счётчик фактов.
- QR-код на текущем URL.

## Стек
- Python 3.10+, Flask 3.0, flask-cors
- API GigaChat (Сбер)
- Tesseract OCR
- pdfmake (PDF в браузере)
- Bootstrap 5.3
